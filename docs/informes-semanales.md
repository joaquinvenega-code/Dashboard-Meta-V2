# Informes semanales

## Descargar desde Orión

En **Configuración → Informes semanales** aparece el listado de informes disponibles, organizado por semana y cliente. Conectá tu cartera con Google y presioná **Descargar PDF** junto al cliente que quieras enviar.

El listado conserva las últimas cuatro semanas. Cada archivo está disponible durante 28 días desde su generación. Si aparece «Requiere revisión», ese cliente no tiene un PDF válido para esa ejecución. El botón **Actualizar** vuelve a consultar el listado.

## Elegir clientes

Marcá **Cliente activo** y **PDF los lunes** únicamente para los clientes que correspondan. Tener acceso a una cuenta publicitaria o mostrarla en el tablero no la incorpora automáticamente. Una cuenta consolidada genera un único PDF.

La automatización utiliza el formato de **Detalle de cuentas** y respeta el tipo de cliente, las métricas visibles y las opciones de impresión guardadas. El período corresponde a la semana completa anterior, de lunes a domingo.

## Guardar la cartera

Usá **Guardar esta cartera** para guardar por primera vez. Después, los cambios se sincronizan mientras la sesión de Google esté conectada. **Cargar cartera guardada** recupera la configuración en otro navegador y conserva un respaldo antes de reemplazar los datos locales. **Exportar respaldo** permite descargar una copia de la configuración.

Las ventas manuales que deban aparecer en una semana deben tener su fecha registrada. Los informes descargados quedan listos para que los revises y envíes a cada cliente.
